# Quick Start Guide 🚀

Get your Cozy Habit Tracker up and running in minutes!

## Installation

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will open at `http://localhost:5173`

## First Time Setup

When you first open the app, you'll see three main sections in the sidebar:

### 1️⃣ Work Planner (Orange/Terracotta theme)
Start here to organize your work life

### 2️⃣ Personal Planner (Green/Sage theme)
Manage your personal tasks and wellness

### 3️⃣ Habit Tracker (Brown theme)
Build and track daily habits

## Getting Started with Each Section

### Work Planner Quick Start

1. **Add Your First Task**
   - Select a priority level (High/Medium/Low)
   - Type your task
   - Press Enter or click the + button
   - Check it off when complete!

2. **Schedule a Meeting**
   - Scroll to "Meetings & Appointments"
   - Enter meeting title
   - Set date and time
   - Add optional notes

3. **Block Your Time**
   - Go to "Time Blocks" section
   - Name your focus session
   - Set start and end times
   - Click "Add Time Block"

4. **Set Work Goals**
   - Scroll to the Goals section
   - Enter goal title and description
   - Choose short-term or long-term
   - Use the slider to update progress

### Personal Planner Quick Start

1. **Track Your Meals**
   - Select meal type (Breakfast/Lunch/Dinner/Snack)
   - Describe what you're eating
   - Click "Add Meal"

2. **Log Exercise**
   - Enter exercise type (e.g., "Running", "Yoga")
   - Set duration in minutes
   - Add optional notes
   - Click "Log Exercise"

3. **Monitor Expenses**
   - Choose a category
   - Enter the amount
   - Add a description
   - See your monthly total update automatically

4. **Practice Gratitude**
   - Scroll to the Gratitude Journal
   - Fill in 3 things you're grateful for
   - Select your mood with emoji

### Habit Tracker Quick Start

1. **Create Your First Habit**
   - Click "Create New Habit" at the top
   - Name your habit (e.g., "Drink 8 glasses of water")
   - Choose a category (Health, Productivity, etc.)
   - Select frequency (Daily recommended for beginners)
   - Click "Add Habit"

2. **Start Tracking**
   - Find your habit in the Daily Tracker table
   - Click the checkbox for today
   - Watch your streak counter (🔥) increment!

3. **Build Consistency**
   - Check off habits daily
   - Watch the monthly calendar fill up
   - See your progress in the 30-Day Progress section
   - Maintain streaks for motivation!

## Tips for Success 🌟

### Best Practices

1. **Start Small**
   - Begin with 3-5 core habits
   - Add more as you build consistency

2. **Daily Routine**
   - Check the app in the morning (plan your day)
   - Update during the day (log activities)
   - Review at night (reflection and gratitude)

3. **Use Priority Levels**
   - Mark urgent work as "High" priority
   - Focus on high-priority items first

4. **Track Everything**
   - Meals help identify patterns
   - Expenses reveal spending habits
   - Exercise logs motivate consistency

5. **Set Realistic Goals**
   - Make goals specific and measurable
   - Update progress weekly
   - Celebrate small wins

### Habit Tracking Tips

- **Morning Habits**: Check these off right after waking
- **Evening Habits**: Set a reminder before bed
- **Streaks**: Don't break the chain! Even one day counts
- **Categories**: Use them to balance different life areas
- **Monthly View**: Check it weekly to see patterns

## Keyboard Shortcuts ⌨️

## Understanding the Interface

### Sidebar Navigation
- Click any section to switch views
- Collapse sidebar with hamburger menu (on mobile)
- Current date shown at bottom

### Color Coding
- **Terracotta/Orange**: Work-related items
- **Sage/Green**: Personal items
- **Priority Colors**:
  - Red = High priority
  - Yellow = Medium priority
  - Green = Low priority

### Streak Counter (🔥)
- Shows consecutive days of habit completion
- Resets if you miss a day
- Updates automatically

### Monthly Calendar Heat Map
- Darker colors = more habits completed
- Click dates to see completion count
- Today has a ring indicator

## Data & Privacy

### Your Data is Safe
- Everything saved to browser localStorage
- No cloud sync (your data stays on your device)
- No account required
- No tracking or analytics

### Clearing Data
If you want to start fresh:
1. Open browser DevTools (F12)
2. Go to Application > Local Storage
3. Find 'cozy-habit-tracker-storage'
4. Delete it

Or just clear browser data for this site.

## Troubleshooting

### Data Not Saving?
- Check if localStorage is enabled in your browser
- Make sure you're not in incognito/private mode

### App Not Loading?
- Refresh the page
- Clear browser cache
- Check console for errors (F12)

### Slow Performance?
- Close other browser tabs
- Clear old data you don't need
- Try a different browser

## Daily Workflow Example

Here's a suggested daily routine:

**Morning (5 minutes)**
- Open Work Planner
- Add today's tasks with priorities
- Block time for important work
- Check meetings for the day

**Throughout the Day**
- Check off tasks as completed
- Log meals and exercises
- Track expenses as they happen
- Update time blocks if needed

**Evening (5 minutes)**
- Check off remaining habits
- Write gratitude entries
- Update goal progress
- Quick reflection on the day

**Weekly Review (15 minutes)**
- Review habit completion rates
- Check monthly calendar patterns
- Adjust goals if needed
- Plan next week's priorities
